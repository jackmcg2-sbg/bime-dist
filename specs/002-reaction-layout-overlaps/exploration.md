## Synthesis *(evolving — regenerate whole, never append)*

> Regenerated by: claude-opus-5-5 at 2026-10-08T15:05Z, incorporating entries ≤ E14 / V6 / O18.

**The cause is BIME's 2D layout, not the reaction-figure code.** Each molecule
in the reaction is laid out on its own by `Layout.layout`. The crossings and
clashes are present in that standalone layout before the figure code runs (E3).
The figure then draws the coordinates faithfully. Feature 001 placed labels and
map numbers well wherever the layout left room for them.

**What goes wrong.** About 70% of crossings in the pilots are *fold-backs*: a
chain or branch drawn back over a part of the molecule more than five bonds
away (E4). Local ring distortion is rare. This is the classic failure of greedy
chain placement without a global collision check. The result is also unstable:
the same molecule, written with a different atom order, gets anywhere from 8 to
54 crossings (E5). The pipeline has crossing-reduction and force-directed
passes (Steps 10–11, `SMSDLayout`). They run, but they don't remove these
crossings (E7). SDG rescue and refinement give a small improvement at 2–3× the
cost (E8, E12).

**How common.** On 367 unique heavy-atom molecules from a 1-in-57 corpus sample
(E10):

| atoms | BIME: has a crossing | BIME: clean | RDKit: has a crossing |
|---|---|---|---|
| 2–15 | 0% | 98% | 0% |
| 16–30 | 12% | 75% | 2% |
| 31–50 | 39% | 53% | 0% |
| 51–80 | 85% (mean 13) | 14% | 0% |
| 81+ (n=6) | 100% | 0% | 33% |

Metabolites with more than 50 atoms are almost always drawn with crossings.
Cofactors (NAD(P), CoA, folates) and glycolipids are the common cases.

**A clean layout is achievable.** RDKit and CoordGen lay out every pilot
molecule with zero crossings and zero crowded pairs (E9), and nearly the whole
corpus sample cleanly (E10). The coordinates already stored in the
maintainer's .rxn files (written by RDT/CDK) are also clean: 0–2% of molecules
with crossings up to 80 atoms (E13).

**A separate correctness defect found on the way (E11, V5).** The CLI loads a
smaller set of modules than the browser bundle. It never loads `SMSDLayout.js`,
`SDGLayout.js` or `editor/sdg/*` (E6). Step 16 of the layout therefore never
runs, and **the CLI draws every cis double bond as trans** (cis-2-butene,
maleate, oleate). The browser module set draws them cis. Every CLI figure of an
unsaturated lipid is chemically wrong today. The test shim has the same gap, so
tests run on the CLI module set.

**Design space (M3).**

- **A. Module parity.** The CLI and test shim load the same layout modules as
  the bundle. This fixes the cis/trans error and gives a small layout gain
  (E8, E12). Layout becomes 2–3× slower, and it does not fix fold-backs. Small
  and well bounded; it could ship on its own as a correctness fix.
- **B. Multi-start.** Lay out several atom orderings and keep the best by
  `LayoutQuality`. This is cheap to build and helps: on the pilots, best-of-10
  takes GDA1 from 13 to 8 crossings and CE2872 from 15 to 1 (E5). It does not
  reach zero, and cost grows with the number of orderings tried.
- **C. Fold-back repair pass.** After layout, rotate or flip subtrees about
  acyclic single bonds (and stretch where needed) to remove crossings and
  clashes, scored by `LayoutQuality`. This is the CDK `LayoutRefiner`
  approach. BIME's own `LayoutRefiner` only flips rings and aligns the axis
  (E14). It targets the dominant ~70% class directly. Medium effort; the main
  risk is regressions in the existing layout tests.
- **D. Rewrite chain placement** to be collision-aware, CoordGen-style. This
  gives the best ceiling but is a large change inside a 5.5k-line module.
- **E. Use input coordinates.** The CLI reads RXN/MOL files and keeps their
  coordinates when they are good, re-laying out only when quality is poor
  (E13). This fixes the maintainer's own figures immediately, but only for
  inputs that carry coordinates. It needs a CLI RXN reader; today only the
  browser editor parses MOL (E15).
- **F. Use RDKit.** Ruled out for the BIME core by the zero-dependency
  principle (constitution I). See Dead ends.

**Contradictions and open points carried forward.**

- The "clean" rate on 16–30-atom molecules is *lower* with the SDG modules
  loaded (65% vs 75%). The likely reason is that correctly drawn cis bonds put
  atoms legitimately closer than 0.6 BL, which the crowding metric counts.
  Unverified.
- The corpus sample dropped 271 of the extracted molecules that RDKit could not
  sanitise (valence or charge issues). The size distribution of the sample is
  therefore biased; the dropped set was not measured.
- The pilot layouts are history-dependent: GDA1's reactant and product are the
  same molecule (it is a transport reaction), yet within one process they got
  37 and 11 crossings (E3, E5; known-defects.md).

**What would decide go/no-go.** The evidence for *go* is strong: the problem is
real, common, measurable, and solved elsewhere. The open choice is **scope**.
Candidates: A alone (small, fixes a correctness bug); A + C (the fold-back
class, measurable against this corpus); or E for figures from .rxn input. B is
a possible stopgap or a component of C. A prototype of C on the 51–80-atom
sample would show how close to RDKit it gets.

## Decision *(human-only)*

- **Outcome**: go
- **Rationale**: Gate E, 2026-10-08, the maintainer chose "Go" with scope "A + C".
  The overlaps come from BIME's layout (V1 refuted, E3, E4). They are common
  above 30 atoms (E10) and solvable (V4). Module parity also fixes a verified
  cis/trans correctness defect in the CLI (V5).
- **Seed for /speckit-specify**: Reaction-figure layout quality, in two parts.
  (A) Module parity: the CLI (`tools/bime-cli.js`) and the test shim load the
  same layout modules as the browser bundle (`SMSDLayout.js`, `SDGLayout.js`,
  `editor/sdg/*`), so CLI figures draw cis double bonds as cis and get the same
  layout as the browser. (C) A fold-back repair pass in BIME's 2D layout:
  after placement, remove bond crossings and atom clashes caused by chains or
  branches folded back over the molecule. It rotates or flips subtrees about
  acyclic single bonds (stretching where needed), scored by `LayoutQuality`,
  without distorting rings or changing stereo depiction. Measured against the
  exploration's corpus sample (367 heavy-atom molecules) and the three pilot
  reactions, with RDKit as the external reference. Out of scope: reading
  coordinates from RXN/MOL input (option E), rewriting chain placement
  (option D), and any runtime dependency.
